## PR 50 — **Graph‑owned images** (ImageArena; behavior‑neutral)

**Goal:** Make graph handles map to **real** textures/views that the graph owns. Passes must fetch views via `ExecCtx` only.

**Files & steps**

1. **Image types** (`gfx/renderer/graph.rs`)

   * Add:

     ```rust
     #[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
     pub struct ImageDesc {
         pub format: wgpu::TextureFormat,
         pub size: [u32; 2],
         pub msaa: u32,
         pub usage: wgpu::TextureUsages,
     }

     struct ImagePlan { desc: ImageDesc }

     pub struct ImageArena {
         textures: Vec<wgpu::Texture>,
         views:    Vec<wgpu::TextureView>,
         descs:    Vec<ImageDesc>,
     }
     ```
   * In `Graph::compile`:

     * For each declared `Handle<Img>`, compute an `ImageDesc` from `ImageKind` and IO (see **usage rules** below) and push an `ImagePlan`.
     * Store plans on the compiled graph.

2. **Instantiate** (`Graph::execute`)

   * Create an `ImageArena` per frame:

     ```rust
     let mut arena = ImageArena { textures: vec![], views: vec![], descs: vec![] };
     for plan in &self.plans {
         let tex = device.create_texture(&wgpu::TextureDescriptor {
             label: /* from pass/name/idx for debugging */,
             size:  wgpu::Extent3d { width: plan.desc.size[0], height: plan.desc.size[1], depth_or_array_layers: 1 },
             mip_level_count: 1,
             sample_count: plan.desc.msaa,
             dimension: wgpu::TextureDimension::D2,
             format: plan.desc.format,
             usage: plan.desc.usage,
             view_formats: &[],
         });
         let view = tex.create_view(&wgpu::TextureViewDescriptor::default());
         arena.descs.push(plan.desc);
         arena.views.push(view);
         arena.textures.push(tex);
     }
     self.image_arena = Some(arena);
     ```

3. **ExecCtx API**

   * Extend `ExecCtx`:

     ```rust
     impl<'a> ExecCtx<'a> {
         pub fn view_color(&self, h: Handle<Img>) -> &wgpu::TextureView { /* map handle → arena.views[idx] */ }
         pub fn view_depth(&self, h: Handle<Img>) -> &wgpu::TextureView { /* same */ }

         // For future resolve pass (PR 51):
         pub fn texture(&self, h: Handle<Img>) -> &wgpu::Texture { /* arena.textures[idx] */ }
         pub fn desc(&self, h: Handle<Img>) -> ImageDesc { /* arena.descs[idx] */ }
     }
     ```
   * **Replace** any remaining `attachments.*` reads in passes with `ctx.view_*`.

4. **Usage rules** (derive in `compile`)

   * Color **write**: `RENDER_ATTACHMENT`.
   * Later **sample**: add `TEXTURE_BINDING`.
   * Depth **write**: `RENDER_ATTACHMENT`.
   * Depth **sample**: add `TEXTURE_BINDING`.
   * If any pass copies to/from it: add `COPY_SRC`/`COPY_DST` accordingly.

**Tests (CPU)**

* Build test ensures passes compile using `ctx.view_*`.
* Small logic test: two distinct handles → two distinct arena slots (compare `as_ptr()` of views or ids).

**Acceptance**

* Visual parity; `xtask ci` green.
* Grep shows passes no longer pull `renderer.attachments.*`.

**Docs**

* `docs/audit/log.md`: PR 50 entry (Changes/Validation).
* `refactor-progress.md`: mark “graph owns images (no aliasing)” done.

**Commit subject**


## PR 51 — **MSAA resolve modeled as a pass** (behavior‑neutral)

**Goal:** When MSAA > 1, Main writes a **multisampled** color; a distinct **ResolvePass** resolves into single‑sample HDR used by post & Present. When MSAA == 1, Main writes HDR directly.

**Files & steps**

1. **Graph build** (`gfx/renderer/render.rs`)

   * Decide sample count (from renderer config/env).
   * If `samples > 1`:

     ```rust
     let msaa_color = gb.image(ImageKind::Color { format: HDR_FMT, size, msaa: samples });
     let hdr_color  = gb.image(ImageKind::Color { format: HDR_FMT, size, msaa: 1 });
     let depth      = gb.image(ImageKind::Depth { format: DEPTH_FMT, size, msaa: samples });

     MainPass::declare(&mut gb, /* color = msaa_color, depth */);
     ResolvePass::declare(&mut gb, msaa_color, hdr_color);
     // post reads/writes single-sample hdr_color (or ping-pong from PR 46)
     ```
   * Else (samples == 1):

     ```rust
     let hdr_color = gb.image(ImageKind::Color { format: HDR_FMT, size, msaa: 1 });
     let depth     = gb.image(ImageKind::Depth { format: DEPTH_FMT, size, msaa: 1 });

     MainPass::declare(&mut gb, /* color = hdr_color, depth */);
     ```

2. **MainPass** (`passes_graph.rs`)

   * If MSAA > 1: `.writes(msaa_color)` (no resolve target here).
   * If 1: `.writes(hdr_color)`.

3. **ResolvePass** (`passes_graph.rs`)

   * Declaration:

     ```rust
     pub struct ResolvePass;
     impl ResolvePass {
         pub fn declare(b: &mut GraphBuilder, src_msaa: Handle<Img>, dst_hdr: Handle<Img>) {
             let _ = b.pass("Resolve", |ctx: &mut ExecCtx| {
                 // Validate formats/sizes
                 let s = ctx.desc(src_msaa); let d = ctx.desc(dst_hdr);
                 debug_assert!(s.format == d.format && s.size == d.size && s.msaa > 1 && d.msaa == 1);
                 // Resolve
                 let src = ctx.texture(src_msaa);
                 let dst = ctx.texture(dst_hdr);
                 // SAFETY: wgpu requires same size/format; msaa>1 → 1
                 ctx.encoder.resolve_texture(
                     src, 0, 0, 0,
                     dst, 0, 0, 0,
                     wgpu::Extent3d { width: s.size[0], height: s.size[1], depth_or_array_layers: 1 }
                 );
                 push_stats(ctx, "Resolve", 0, 0, /* hits/misses delta = 0 */);
             })
             .reads(src_msaa)
             .writes(dst_hdr);
         }
     }
     ```

4. **Post & Present**

   * Ensure post chain uses **single‑sample** HDR (from PR 46 ping‑pong).
   * Present samples that final single‑sample HDR.

**Tests**

* CPU hazard test: a write to `msaa_color` **after** Resolve should be rejected by cross‑pass monotonic rule.
* (Optional device smoke under `wgpu-tests`): run both `samples=1` and `samples=4`.

**Acceptance**

* Visual parity (`samples=1` default).
* With `samples>1` locally, no validation errors; post reads single‑sample HDR.

**Docs**

* Log PR 51; update risk plan note (“resolve constraints: same format/size, src msaa>1 → dst 1”).

**Commit subject**

```
renderer(PR51): MSAA ResolvePass (msaa_color → hdr_color); Main writes msaa when samples>1; post & Present consume single-sample HDR
```

## PR 52 — **Aliasing of transient images** + **peak memory** (feature‑gated)

**Goal:** Reduce peak VRAM by **aliasing** images with **non‑overlapping lifetimes**; surface the graph’s **peak memory** estimate in the perf HUD. Default OFF.

**Files & steps**

1. **Liveness** (`graph.rs`)

   * During compile, compute for each image handle a live interval `[first_use_pass_idx, last_use_pass_idx]` from pass IO.

2. **Aliasing planner** (feature `graph_aliasing`, default off)

   * If feature **enabled**:

     * Keep a pool of reusable slots keyed by **compatible** `ImageDesc` (same `format`, `size`, `msaa`; and `usage` must be a **superset** of required usage).
     * Use interval‑packing: for each new image, try to reuse a slot whose last live pass `< first_use` of the new image; otherwise allocate a new texture.
     * Record mapping: `handle → slot_id`.

3. **Arena instantiation** (`Graph::execute`)

   * If aliasing **off**: instantiate per‑image textures (as in PR 50).
   * If **on**: instantiate per **slot**, create a view per **handle** into the same texture (default full view).
   * Add debug tracing when `RA_GRAPH_TRACE=1`:

     ```
     [graph] Img#7 (HDR fmt RGBA16F 1920x1080 x1) -> Slot#2 (alias of Img#3)
     ```

4. **Peak memory estimate**

   * Compute:

     * **Without aliasing**: sum of all image footprints.
     * **With aliasing**: sum of slot footprints (= actual peak).
   * Footprint per image/slot:

     ```
     bytes = width * height * bytes_per_pixel(format) * samples
     ```
   * Store in a `GraphStats` exposed to perf HUD (e.g., `graph_peak_mem_mb`).

**Tests**

* CPU:

  * Interval‑packing unit test with crafted intervals (A:[0,1], B:[2,3] → 1 slot; A:[0,2], B:[1,3] → 2 slots).
  * Compatibility test: mismatched `msaa` or `format` **must not** alias.
* (Optional device smoke, feature on): build a graph with two non‑overlapping temps; assert `arena.textures.len()` reduced.

**Acceptance**

* Default build (feature off) → visual parity; HUD shows a **computed** non‑aliased peak.
* With feature on locally: reduced slot count and lower peak shown; no hazards triggered.

**Docs**

* `docs/audit/log.md`: PR 52 entry.
* `risk-and-test-plan.md`: add aliasing guardrails & trace toggle.

**Commit subject**

```
renderer(PR52): optional graph aliasing + peak memory stats; interval packing with descriptor compatibility; feature off by default
```
