## PR 46 — Post suite: **ping‑pong color + IO truth** (behavior‑neutral)

**Goal:** Make every post pass hazard‑clean by reading one HDR image and writing another (no read‑write of the same image in a single pass). Remove the ad‑hoc “scene_read” copy.

**Files & steps**

1. **Graph build** (`gfx/renderer/render.rs`)

   * After MSAA resolve (PR 45), treat that resolved single‑sample image as **`hdr_a`**.
   * Create **`hdr_b`**:

     ```rust
     let hdr_a = /* the single-sample HDR from Main/Resolve */;
     let hdr_b = gb.image(ImageKind::Color { format: HDR_FMT, size, msaa: 1 });
     ```
   * Build post chain by **toggling** `(src, dst)` per pass:

     ```rust
     let mut src = hdr_a;
     let mut dst = hdr_b;

     PostAoPass::declare(&mut gb, src, depth, dst); std::mem::swap(&mut src, &mut dst);
     SsgiPass::declare(&mut gb, src, depth, dst);  std::mem::swap(&mut src, &mut dst);
     SsrPass::declare(&mut gb,  src, depth, dst);  std::mem::swap(&mut src, &mut dst);
     BloomPass::declare(&mut gb, src, depth, dst); std::mem::swap(&mut src, &mut dst);

     PresentPass::declare(&mut gb, /* final */ src);
     ```
   * **Delete** `BlitSceneReadPass` and any intermediate copy; we’ll sample directly from `src`.

2. **Pass declarations** (`gfx/renderer/passes_graph.rs`)

   * Update signatures and IO:

     ```rust
     pub struct PostAoPass;  // reads(src color, depth) -> writes(dst color)
     pub struct SsgiPass;    // reads(src color, depth) -> writes(dst color)
     pub struct SsrPass;     // reads(src color, depth) -> writes(dst color)
     pub struct BloomPass;   // reads(src color, depth?) -> writes(dst color)
     ```

     Example:

     ```rust
     pub fn declare(b: &mut GraphBuilder, src: Handle<Img>, depth: Handle<Img>, dst: Handle<Img>) {
         let _ = b.pass("PostAO", |ctx: &mut ExecCtx| {
             ctx.renderer.pass_ao(ctx.encoder /* sampling ctx.view_color(src) */);
             push_stats(ctx, "PostAO", 1, 1, /* bg hits/misses delta */);
         })
         .reads(src)
         .reads(depth)
         .writes(dst);
     }
     ```
   * Ensure **all** post passes include `.reads(src)`; remove any in‑place `.writes(src)`.

3. **Pass execution helpers** (`gfx/renderer/passes.rs`)

   * In each `pass_*` helper, **sample** from `ctx.view_color(src)` and set the render target to `ctx.view_color(dst)`. (If helpers currently use raw attachments, convert them to take `&wgpu::TextureView` args or fetch via `ExecCtx` inside closures.)
   * For Bloom: keep additive blend inside the shader or pipeline state, but write to **`dst`** (no “load & overwrite in place”).

4. **Present**

   * Present samples **the final `src`** from the toggle (single‑sample HDR). Ensure the Present BG binds that view (SRV‑capable) and not the MSAA target.

**Tests (CPU)**

* Hazard unit test: building a graph where a post pass tries to `.reads(src).writes(src)` should **fail** (use your existing intra‑pass RW ban).
* Build‑only check that the chain produces the expected pass order and swaps.

**Acceptance**

* Visual parity.
* `xtask ci` green; hazard tests remain strict.
* `BlitSceneReadPass` removed.

**Docs**

* `docs/audit/log.md`: PR 46 entry with “Changes/Validation”.
* `large-files-audit-v2.md`: note shrink from removing the blit pass.

**Commit subject**


## PR 48 — Main **DrawList 2.1** batching (behavior‑neutral)

**Goal:** Actually **use** DrawList in `pass_main` to reduce binds while preserving draw order. Track state‑change counters.

**Files & steps**

1. **DrawList integration** (`gfx/renderer/passes.rs`)

   * Build a `DrawList` in legacy order with keys `(pipeline_id, material_id, mesh_id, flags)` (flags can stay 0 for now).
   * Convert to batches grouped by `(pipeline_id, material_id)` **without reordering meshes within a group**.
   * Emit:

     ```rust
     for b in batches {
         // one-time binds:
         rp.set_pipeline(b.pipeline);
         rp.set_bind_group(… material …);
         stats.pipeline_binds += 1;
         stats.bg_binds      += material_slots_set;

         for draw in b.draws {
             // vb/ib sets + draw
             stats.vb_ib_sets += set_count_for_draw;
             rp.draw_*…
         }
     }
     ```
   * Keep per‑mesh draw calls if index ranges differ; you still get fewer binds.
